§ 05 — Standards

Every build ships against a budget.

Numbers we set before the first commit and check before the last one. If a feature breaks a budget, the feature changes.

  • LCP <0.0s Largest contentful paint on 4G
  • CLS 0.25 Layout shift — nothing jumps
  • PERF 0+ Lighthouse, every category
  • A11Y AA WCAG 2.2 conformance
  • FPS 0 Motion on a mid-range phone
